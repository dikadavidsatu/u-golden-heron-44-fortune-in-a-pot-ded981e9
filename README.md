One kind, funny fortune for a houseplant for make.fun's "Fortune in a Pot" bounty. A single original line about the plant on the windowsill — the morning sun lingering on its leaves a little longer, and its keeper telling guests the plant planned it that way. The program writes the fortune (113 characters, one line) to `/output/entry.txt`, validating it against the competition gate (1–120 characters, not only whitespace, single line) and reading it back to confirm exactly what was written.

## Run it

```sh
node main.ts
```
